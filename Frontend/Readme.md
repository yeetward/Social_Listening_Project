# Setup Guide

Run the web UI locally and connect it to the Django backend.

---

Prerequisites

- Node.js 18+ or 20+
- One package manager: npm, pnpm, or yarn

Check versions:

```bash
node -v
npm -v

2. Clone
git clone <your-repo-url>
cd Frontend

3.  Install 
npm install

4. Environment

Next.js

Create React App
REACT_APP_API_BASE_URL=http://127.0.0.1:8001
